# Ecosol — partner

Norský instalační partner pro střešní solární projekty ve Skandinávii.

## Soubory

### `logo.png` (default)
- Barevné logo (modrá + oranžová), čitelné na bílém i světle šedém pozadí
- Rozlišení: 1000×251px
- **Použití:** Sekce Partneři, footer

### `logo.webp` (originál)
- Webp formát, menší file size
- **Použití:** Pro browsery podporující WebP (98% trh)

### `logo-400w.png` (optimalizovaná velikost)
- Stejné jako logo.png, ale menší (400px wide)
- **Použití:** Mobile, kompaktnější karty

## Použití v kódu

```tsx
// Next.js Image automaticky vybere nejlepší formát
<Image
  src="/images/partners/ecosol/logo.png"
  alt="Ecosol — instalační partner v Norsku"
  width={200}
  height={50}
/>
```
