# Pillar — partner

Ukrajinský výrobce konstrukcí pro solární parky a carporty.

## Soubory

### `logo.png` (default — pro světlá pozadí)
- Wordmark v navy (#030057), žlutá ikona zachovaná
- **Použití:** Sekce Partneři na bílém/světlém pozadí
- Rozlišení: 465×72px (originál upravený)

### `logo-400w.png` (optimalizovaná velikost)
- Stejné jako logo.png, ale menší (400px wide)
- **Použití:** Pokud potřebuješ menší file size

### `logo-white.png` (pro tmavá pozadí)
- Originální bílá verze
- **Použití:** Footer, dark sections, hero overlay

## Použití v kódu

```tsx
// V Partners sekci (bílé pozadí)
<Image
  src="/images/partners/pillar/logo.png"
  alt="Pillar — partner pro solární parky a carporty"
  width={200}
  height={31}
/>

// Ve footeru (navy pozadí)
<Image
  src="/images/partners/pillar/logo-white.png"
  alt="Pillar"
  width={150}
  height={23}
/>
```
