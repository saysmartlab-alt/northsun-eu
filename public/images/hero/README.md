# Hero images

Fotky pro hlavní hero sekce na webu. Velký formát, optimalizované pro různá zařízení.

## Co sem patří

### `hero-main.jpg`
- **Použití:** Homepage hero (background)
- **Doporučený zdroj:** `floating-solar.jpg` (plovoucí elektrárna s lávkou)
- **Formát:** JPG nebo WebP
- **Rozlišení:** 2400x1600px minimum (4K-ready)
- **Optimalizace:** komprese 85%, progressive JPG

### `hero-mobile.jpg` (volitelné)
- **Použití:** Mobilní verze hero (pokud se hodí jiná kompozice)
- **Rozlišení:** 1200x1600px (vertikálně orientovaný)

### Pravidla
- Tmavší overlay bude aplikován v CSS (gradient navy 80% → 50%)
- Fotka musí mít hlavní subjekt v levé třetině (kvůli text overlayi)
- Vyhnout se extrémně světlým fotkám (text by nebyl čitelný)
